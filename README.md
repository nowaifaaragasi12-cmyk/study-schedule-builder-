# Project-Title-StudyLab-Student-Study-Schedule-Builder
Project Purpose: Study-Lab is a student study schedule builder that helps students organize their daily study activities. It allows students to manage their time, prioritize subjects, and improve their study habits. Its goal is to make studying more organized and productive.
Planned Features: Create Study Schedules – Create and organize daily study schedules.
 Manage Subjects – Add, edit, and delete subjects or school tasks.
Set Study Reminders – Set specific times for studying and taking breaks.
Track Progress – Monitor completed and unfinished study tasks.
